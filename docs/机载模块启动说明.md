# 地面站按需启动机载模块

入口：地面站「系统设置 → 机载程序」，或连接设置顶部「机载程序」按钮。

## 连接与启动

1. 填写机载地址、SSH 用户和机载工程绝对路径，点击「连接机载」。需要预先配置并验证 SSH 公钥登录及主机指纹。这里不保存 SSH 密码。
2. 连接会启动用户级后台管理进程和本机 SSH 任务隧道，不启动飞行、云台、YOLO 或 RViz。隧道使用一个空闲本地端口，不占用或终止已有隧道。
3. 选择预设或单独勾选功能，点击「启动所选模块」。选择和连接本身不会启动所选模块。飞行启动固定使用 remote / --start-only，不解锁、不起飞、不执行航线。
4. 查看各模块状态和日志。飞行核心注册齐全后，地面站会尝试连接任务网关。节点运行不等于传感器、定位、控制器或视频已经就绪，业务状态以真实任务遥测、相机状态和模块日志为准。

## 功能与依赖

| 功能 | 依赖和行为 |
| --- | --- |
| 飞行栈 | 整组启动 MAVROS、雷达定位、EKF、规划器、控制器、任务网关；默认不启动 RViz、云台和 YOLO |
| 云台控制 | 独立启动云台 ROS 节点，不自动旋转，不要求飞行栈 |
| YOLO 识别 | 独立读取相机视频并加载模型，不依赖云台控制节点；强制关闭本地识别窗口 |
| 起飞自动录像 | 自动选择云台控制；不自动选择飞行栈。缺少飞行状态时等待，得到有效飞行事件后由原有云台逻辑执行录像 |
| 保存识别视频 | 自动选择 YOLO，不自动选择飞行或云台；保存带框视频到机载配置目录 |
| RViz 调试 | 独立启动，需要机载图形桌面及授权；没有图形桌面时报告失败，其他模块继续运行 |

取消 YOLO 会同时取消保存识别视频；取消云台会同时取消起飞自动录像。勾选的变化只修改下一次启动选择，不会停止已运行模块。已运行云台/YOLO 的录像选项改变时，需要先明确停止该模块，再重新启动；不会自动重启。

「仅连接」不启动工作模块；「仅航点飞行」只选择飞行栈；「地面识别调试」选择云台和 YOLO；「完整巡检」选择飞行栈、云台和 YOLO，录像另选。保存预设后，下次仍需点击启动。

## 生命周期和故障

- 管理进程通过 SSH 的 JSON 请求控制，仅使用机载私有 Unix socket，不开放网络管理端口；仅启动受限的已知模块。
- 后台模块不依赖 VSCode、SSH 终端或远程桌面的连接持续存在。关闭地面站或断开管理，只关闭本机任务隧道，不停止机载模块。
- 每个模块单独运行、记录日志。RViz 或 YOLO 故障不会触发飞行栈停止。飞行核心节点自身的原有故障处理保持有效。
- 停止飞行栈会等待新的 MAVROS 飞行状态，要求飞控连接、未解锁、已落地；不满足或无法读取状态时拒绝停止。停止后等待日志、rosbag 和子进程收尾，再重新启动。
- 只停止本管理进程拥有的模块。检测到外部启动的同名节点时显示「外部启动，不接管」，拒绝重复启动；不会按进程名批量杀进程。
- 本实现是用户级后台管理，不配置开机自启，也不自动恢复/重启飞行。管理进程崩溃或源码更新后，已存在的外部节点仍受防重复启动保护。
- RViz 是可选调试工具。直接执行原启动脚本时，remote 模式默认无界面；可用 UAV_START_RVIZ=true 打开独立 RViz。其他模式保留原默认显示行为。

## 范围

本次实现模块启动、停止、依赖联动、SSH 隧道和状态/日志查看。云台按航点自动旋转/扫描仍需独立扩展远程航点动作协议；启动云台节点本身不意味着航点已有云台动作。

## 非交互启动硬件配置

MID360 的 BD_LIST 由 sh_files/onboard.env 显式提供，后台启动不再依赖桌面终端的 ~/.bashrc。更换雷达时修改该配置；命令行已导出的 BD_LIST 仍优先。机载管理和任务遥测是两条连接：任务网关运行后才提供飞控/定位遥测，管理连接可在飞行栈停止时使用。使用管理连接时，连接设置会显示并使用实际分配的本地任务隧道端口。
