## 操作语义

当前代码按 CH8 的 PWM 值分类，不根据遥控器开关的外观或物理方向判断：

- DOWN：1999 附近，进入该档请求降落。
- MIDDLE：1499 附近；从 UP 到这里表示返程，并保持返程目标高度 1 m。
- UP：999 附近，表示启动航线。

本次 CH5/CH6 一直为 1999，因此没有发生 CH6 退出指令模式导致自动 LAND 重试被取消的问题。没有 LAND 的原因是 CH8 没有进入降落档。

CH7 的飞控侧功能没有保存在本次日志中，因此不能由 PWM 变化断言它是急停、解锁或其他功能。

航线完成与返程完成均只结束航点任务，不会自动降落。第一次返程在 18:00:28 已完成，之后无需再次切 UP；重复 UP 被拒绝的日志为 `Gimbal route already used in this run; land and restart the complete stack before repeating it`，这是既有的一轮云台任务限制。

AUTO_HOVER 中，下拉 CH3 会通过 `set_hov_with_rc()` 下调悬停目标高度。本次 `rc_reverse/throttle=true`，油门向下对应目标高度下降，和记录的高度变化一致。此行为不会直接生成 LAND 消息。

## 后续使用

要触发当前项目自动降落，应在已确认现场条件允许时将 **CH8 拨到 DOWN（读数约 1999）**，保持 CH5/CH6 的自动控制许可；或使用已有的 `./sh_files/land.sh`。该脚本通过 `/mission/land` 停止航线并重发 LAND，等待控制器接受。

本轮末尾已经落地上锁且任务故障锁止，应退出并重启完整飞行栈后再开始新一轮。不要在同一次运行中反复用 UP 重启云台预设航线。
