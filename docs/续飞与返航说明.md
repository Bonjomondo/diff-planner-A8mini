# 远程任务：追加续飞与返航

机载项目：`/home/ly/Documents/diff-planner-A8miniV2`；地面站：`agri_gcs_visual`。两端都需要使用本次修改后的程序。源码修改和编译不会替换已经运行的进程，下一轮地面准备时重新启动两端程序。

## 执行中更新

任务处于 `FLYING` / `HOVERING` 时，可以追加航点或修改尚未执行的后续航点，点击“更新后续航点”。机载确认新版本后，当前路段继续执行，之后接着执行更新后的后续航点。地面站锁定已完成和当前执行的航点；修改草稿本身不发送飞行指令。

## 完成后追加续飞

1. 原航线变为“任务完成”后，保留已完成航点，在末尾添加新航点。
2. 点击“追加后续航点”，等待机载确认。原任务 ID 保持一致，版本递增，已完成计数保留，状态变为 `READY`。
3. 点击“开始续飞”。从第一个未完成航点执行。例如已完成 3 个、追加第 4 个，只执行第 4 个。

“追加”的确认不会自动启动飞行。需要飞机仍在空中、OFFBOARD、控制器悬停就绪，且定位和规划器有效。RC8 从上档拨到中档用于返航，续飞使用地面站的“开始续飞”。

新上传一整份航线仍表示新任务，进度从零开始。重新打开地面站后，需要重新核对定位会话；缺少匹配的确认航线时不会擅自推断已完成前缀。

## 返航

- 触发：RC8 上档 → 中档，或地面站“返航”。
- 目标：本次定位会话中，起飞解锁前记录的地面位置 X/Y。
- 高度：保持触发返航时的局部坐标 Z，由 Diff-Planner 规划到目标。
- 到达：悬停，降落需要另外触发。
- 返航替换当前航点任务，生成独立的返航任务 ID；不再继续原航线，返航期间拒绝航点更新。到达后可明确上传新的航线。
- 重复返航请求不会重复启动；旧任务、旧版本、旧定位会话的请求会被拒绝。

没有记录到有效起飞前位置、定位失效或重置、飞机未在空中、控制器/规划器状态无效、降落或故障锁定时，返航请求会被拒绝并给出原因。机载在空中重启后需要重新建立有效的下一轮飞行，不会把当前空中位置当作起飞点。
