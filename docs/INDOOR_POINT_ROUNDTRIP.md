# LIVE 地图自动起降与单点往返

2026-10-22：任务面板只提供自动流程，不再提供人工起飞后记录返回点的模式。

## 使用步骤

1. 等待真实 LIVE 地图、自动任务服务、定位坐标核对和实际规划器围栏就绪。
2. 无人机在地面未解锁、静止约两秒，点击“确认当前位置为起降点”。记录的是 IMU 参考点的 world 位置，不是物理地面平面。
3. 在俯视图选择目标 P。默认目标 Z 是起飞位置 Z 加控制器实际起飞上升量，也可单独设置目标 world Z。world Z 不等于离地高度。
4. 设置目标悬停秒数，上传自动往返任务。上传只保存任务，不起飞。
5. 检查起降位置、目标、高度和通道，点击“自动起飞并执行”并在对话框确认。此确认会授权本次自动解锁与起飞。
6. 自动起飞并稳定悬停后前往 P，悬停后返回起飞点上方，再自动降落。只有收到新鲜 FCU 地面状态且电机已锁定，才显示完成。

终止会停止任务、规划和自动起降，不继续返航或降落；空中不会主动锁定电机。现场须按原遥控器接管流程处理。一次飞行完成或失败后先检查机体并重启任务/控制流程，不自动再次起飞。

## 机载准备

只使用新目录 `/home/ly/Documents/diff-planner-A8mini-gcs-mission`，不操作旧目录。打开地面站仍只自动启动传感器建图，不自动启动飞行控制。

现场须重新核验本次连续 world 会话的围网、顶网、地面和机体中心允许范围，并启用实际规划器围栏。保存的旧围栏默认 disabled，不能在地图重启后直接复用。完整起降通道，包括落地时 IMU 位置，须在当前围栏及滚动地图内、已被观测为空闲，且不在占据/膨胀栅格或虚拟地面/顶面内。只有巡航高度的围栏不能直接用于自动起降；不能未经测量扩大边界以通过检查。

定位/EKF、规划器和轨迹服务器经核验就绪后，自动任务入口是：

```bash
roslaunch px4ctrl run_ctrl_indoor_automatic.launch takeoff_height:=<现场核验的上升米数>
roslaunch multipoint indoor_roundtrip.launch
```

这些是现场部署说明，本次软件更新没有执行以上真实飞行控制启动命令。起飞高度必须显式提供；速度和机体控制参数沿用已有配置，仍需核验。自动任务入口只启动适配器和网关，不启动定位或控制器。

控制器要求有效 world 定位、IMU、飞控连接、地面未解锁、静止、正常电压，以及遥控器允许悬停/轨迹且摇杆居中。不使用 no_RC。此配置下地面 RC 开关边沿不会自动进入 OFFBOARD；明确 TAKEOFF 后才切模式和解锁。模式切换失败不解锁，切换等待期间再次检查取消、传感器、遥控和 FCU 条件；FCU 重启路径禁用。

## 状态与保护

协议 upload 增加 `automatic=true` 和 `ground_origin={x,y,z}`，保存两个航点 `[P,R]`。R.xy 与起飞点一致，R.z 与控制器起飞高度一致。旧后端未声明 automatic_supported 时，界面不会执行自动任务。

状态依次为 READY → TAKING_OFF → FLYING/HOVERING → LANDING → COMPLETED。明确 start 才发送一次起飞命令；相同请求去重，不自动重发。空中就绪且定位速度不超过 0.10 m/s，连续稳定约一秒后才发布目标；不再要求距记录的返航参考点 R 不超过 0.15 m。到达返航点不提前完成，落地但仍解锁也不完成。

控制器在 TAKING_OFF 任务阶段先进入地面的 `PREPARING_TAKEOFF`，等待请求之后收到的新鲜 OFFBOARD 状态，最多 2.5 秒；MAVROS 模式服务接受请求不等于已收到模式反馈。等待期间持续处理传感器/取消并发送怠速设定值，不阻塞控制循环；地面位置、遥控、定位、电量检查变化或超时均在解锁前退出。收到模式反馈且当前地面检查通过后才请求一次解锁，再进入 AUTO_TAKEOFF。任务为模式及解锁的正常 FCU 反馈提供最多 4 秒确认时间，期间地图、通道及输入保护保持有效。

2026-10-22 首次现场尝试暴露旧版 0.1 秒固定等待与约 1 Hz FCU 状态反馈的不匹配：电机未转、未离地，任务 FAILED。维修测试应包含 0.7 秒反馈延迟、反馈不变、准备期间取消/遥控中断，以及 2.2 秒准备阶段的完整往返模拟；通过模拟不等于已完成本次真实飞行验收。

`/indoor_mission/check_endpoints` 使用 GetPlan 类型只检查起降/返航端点是否已知、无占据、无膨胀且在围栏内；原 `/indoor_mission/check_segment` 的整段竖直通道密集采样已移除。上传、开始、返回落点及起降期间检查端点；不再按起降轴的横向或高度偏差终止任务；定位/坐标/遥控条件失效或超时仍会终止自动流程。地面位置移动超过 0.10 m、起飞高度变化超过 0.03 m 要重新确认/上传。默认起飞超时 35 秒、降落超时 60 秒。

终止起降会通过 `/px4ctrl/abort_automatic` 中断控制器起降状态，停止 LAND 重试，锁定任务 FAILED，不能直接恢复。短时 Wi-Fi 中断时，机载健康则继续既有任务；重连只查询，不重放 start。上述终止行为不能代替现场接管和飞控失联处置验证。
